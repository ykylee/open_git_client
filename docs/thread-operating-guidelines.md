# Thread Operating Guidelines

## 문서 정보
- 문서 버전: v0.4
- 기준 개발 버전: v0.0.1
- 작성일: 2026-03-11
- 적용 범위: 현재 요구사항 입력 스레드

## 목적
이 문서는 현재 스레드에서 요구사항을 수집하고 문서화할 때 따라야 하는 운영 방식을 정리한다.

## 운영 원칙
- 이 스레드는 요구사항 입력을 위한 전용 스레드로 사용한다.
- 사용자가 입력한 실제 요구사항은 CRS 형식으로 정리한다.
- 요구사항 문서는 `docs/requirements` 아래에 저장한다.
- `CRS.md`가 작성되거나 수정되면 그 변경 내용을 분석해 `SRS.md`를 생성하거나 갱신한다.
- 이 스레드에서 수행하는 작업은 `codex/요구사항수집` 브랜치에서 반영한다.
- 이 스레드에서 `md` 문서가 생성되거나 수정되면 변경된 문서 내용을 렌더링해서 표시한다.
- 이 스레드에서는 요구사항 수집과 요구사항 문서 갱신만 수행한다.
- 이 스레드에서는 디자인 설계 작업이나 구현 작업을 수행하지 않는다.
- 설계 문서가 필요하면 별도 스레드에서 `docs/design` 아래에 작성한다.

## 문서 관리 대상
- 운영 방식 문서: 이 문서
- 고객 요구사항 문서: `docs/requirements/CRS.md`
- 시스템 요구사항 문서: `docs/requirements/SRS.md`
- 설계 문서: 별도 설계 스레드에서 `docs/design/*`
- 작업 브랜치: `codex/요구사항수집`

## 해석 기준
- 스레드 운영 방식, 문서 작성 절차, 저장 위치 규칙은 운영 규칙으로 분류한다.
- 제품이나 시스템이 충족해야 할 내용만 CRS 또는 SRS 요구사항으로 분류한다.

## 변경 이력
