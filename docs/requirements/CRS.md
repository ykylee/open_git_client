# CRS

## 문서 정보
- 문서명: Customer Requirements Specification
- 문서 버전: v0.5
- 기준 개발 버전: v0.0.1
- 작성일: 2026-03-11
- 상태: 고객 요구사항 등록됨

## 문서 목적
이 문서는 사용자가 이 스레드에 입력한 실제 고객 요구사항을 CRS 형식으로 정리하는 문서다.

## 현재 상태
- 최초 지시는 요구사항이 아니라 이 스레드에서 따를 운영 방식으로 분류한다.
- 운영 방식은 별도 문서에서 관리한다.
- 2026-03-11 기준 상위 수준 제품 컨셉 요구사항이 등록되었다.

## 고객 요구사항

### CRS-001 제품 유형
- 개발 대상 제품은 Git 클라이언트 애플리케이션이어야 한다.

### CRS-002 참고 제품
- 제품 방향을 구체화할 때 `GitKraken`을 참고 대상으로 삼을 수 있어야 한다.
- 이 항목은 상세 요구사항 도출을 위한 레퍼런스 성격의 기준이다.

### CRS-003 핵심 품질 우선순위
- Git과 통신하는 속도는 가장 중요한 요구사항이어야 한다.
- 다른 설계 판단보다 Git 작업 처리 속도와 반응성이 우선 고려되어야 한다.

### CRS-004 대상 플랫폼
- 클라이언트는 Windows용 애플리케이션을 타겟으로 해야 한다.

### CRS-005 구현 및 빌드 제약
- 빌드는 Linux 환경에서도 가능해야 한다.
- 따라서 MFC와 C#은 기술 선택 대상에서 제외한다.

### CRS-006 개발 환경 및 기술 스택
- 개발 언어는 `C++20`을 사용해야 한다.
- UI 프레임워크는 `Qt 6`을 사용해야 한다.
- 빌드 시스템은 `CMake`와 `Ninja`를 사용해야 한다.
- Git 연동은 `libgit2` 중심으로 구성하되 필요한 경우 네이티브 `git` 명령 호출을 병행할 수 있어야 한다.
- Windows 주 개발 환경은 `MSVC 2022`를 사용해야 한다.
- Linux 빌드 환경은 `GCC` 또는 `Clang` 기반이어야 한다.

## 등록 규칙
- 이후 사용자가 기능, 품질, 제약, 범위에 관한 요구사항을 입력하면 CRS 항목으로 등록한다.
- 요구사항 식별자는 `CRS-001` 형식으로 순차 부여한다.
